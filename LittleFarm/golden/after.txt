=== 2. damaged saves (the game must refuse politely, never crash)
empty file -> IOException: not a Little Farm save file
wrong header -> IOException: not a Little Farm save file
unknown entry -> IOException: line 4: unknown entry 'silver'
gold is a word -> IOException: line 4 is damaged: gold abc
gold is negative -> IOException: line 4 is damaged: gold -5
gold is missing its number -> IOException: line 4 is damaged: gold
day is zero -> IOException: line 2 is damaged: day 0
unknown weather -> IOException: line 3 is damaged: weather STORMY
can is a word -> IOException: line 6 is damaged: can lots
unknown seed bag -> IOException: line 7 is damaged: seeds Cabbage 2
seeds missing amount -> IOException: line 7 is damaged: seeds Turnip
villager friendship too high -> IOException: line 12 is damaged: villager 9 5
request for unknown crop -> IOException: line 13 is damaged: request Cabbage 3 360 4
request amount zero -> IOException: line 13 is damaged: request Turnip 0 360 4
request too short -> IOException: line 13 is damaged: request Turnip 3
